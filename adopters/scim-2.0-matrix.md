# Adopter matrix — SCIM 2.0

Generated by `scripts/harvest-adopters.py`. Do not hand-edit.

Measured 2026-09-14 against 51 providers that publish an OpenAPI containing a SCIM path, out of 368 that mention SCIM in the [API Evangelist](https://apis.io) catalog — the largest claim cohort of any standard in this programme, and under a quarter of it is checkable.

**SCIM is ratified, so this table has a column the others do not.** RFC 7643 and RFC 7644 already say what a SCIM server is; what was missing is the measurement beside it. Where the RFC compels nothing, the table says so rather than implying a violation.

There is no `tested` column and there cannot be one: every SCIM operation is authenticated, so there is no anonymous discriminator to probe with.
